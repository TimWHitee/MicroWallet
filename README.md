# Microwallet - The only wallet you need

## How to launch:

### To launch the backend

```
uvicorn main:app --reload
```

### To launch the frontend

```
cd frontend
npm install
npm run dev
```

### MicroWallet is a custodial cryptocurrency wallet designed for simplicity and security. It runs locally on a user's device, ensuring full control over funds while providing essential crypto management features.

## Features

Wallet Creation & Import – Generate a new wallet from scratch or import an existing one.
Mnemonic Phrase Generation – Securely create and store a recovery phrase for your wallet.
Real-Time Crypto Prices – Track cryptocurrency exchange rates in multiple fiat currencies.
Balance Overview – View your holdings in different currencies.
Transaction Management – Easily send and manage transactions directly from your wallet.

## Usage

MicroWallet is a lightweight solution that runs by simply downloading and executing the code on your device.
